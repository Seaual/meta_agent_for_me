# Skill: 小红书风格写作助手

## 概述

本 Skill 定义了小红书（Xiaohongshu / RedNote）平台的内容风格规范，供 content-creator agent 生成符合平台调性的推文正文。

**核心目标**：生成具有「真实感、种草力、互动性」的小红书风格内容。

## 风格规则

### 1. 钩子开头（Hook）

- 首句必须在 15 字以内抓住注意力
- 常用钩子类型：
  - 悬念式：「没想到这个方法真的有用...」
  - 数字式：「3 个让 XX 翻倍的小技巧」
  - 共鸣式：「有没有人和我一样...」
  - 反常识式：「别再 XX 了，真正有效的是...」

### 2. 短段落节奏

- 每段不超过 2-3 行（手机端约 30-50 字）
- 段落之间空一行，制造呼吸感
- 避免大段文字堆砌

### 3. Emoji 使用规范

- 每段开头或结尾可搭配 1-2 个相关 emoji
- 常用 emoji 池：✨ 💡 🔥 🌟 💯 ❤️ 👀 📝 🎯 ✅ 🎉
- 避免过度使用（全文不超过 8 个 emoji）
- emoji 需与内容情绪匹配

### 4. 互动结尾

- 结尾必须包含互动引导，提升评论率
- 常用互动句式：
  - 「你们有没有类似的经历？评论区聊聊～」
  - 「觉得有用的话记得点赞收藏！」
  - 「还有什么想问的？留言告诉我」
  - 「你们更喜欢 A 还是 B？」

### 5. 标签策略

- 文末添加 3-5 个相关话题标签
- 标签格式：`#话题词`
- 标签选择原则：
  - 1-2 个大流量标签（ broad ）
  - 2-3 个精准标签（ niche ）
  - 可加入 1 个品牌/产品相关标签

## 模板示例

### 种草类模板

```markdown
✨ 最近发现了一个超好用的小众好物！

之前一直苦恼 [痛点场景]，
直到朋友推荐了 [产品/方法]。

用了 [时间] 之后，[具体效果]。
真的被惊艳到了 💯

💡 使用小贴士：
1. [技巧1]
2. [技巧2]
3. [技巧3]

姐妹们快试试！

#好物推荐 #种草 #生活小技巧 #[相关话题]
```

### 教程类模板

```markdown
🔥 手把手教你 [目标结果]！

很多姐妹问我 [问题]，
今天整理了一份超详细的攻略 👇

Step 1: [步骤1]
Step 2: [步骤2]
Step 3: [步骤3]

⚠️ 注意事项：
- [注意点1]
- [注意点2]

亲测有效！赶紧码住 ✅

#教程 #干货 #[相关话题]
```

### 分享类模板

```markdown
💡 关于 [话题] 的一些真实想法

最近 [背景/经历]，
想和大家分享几点感悟：

1️⃣ [观点1]
2️⃣ [观点2]
3️⃣ [观点3]

每个人的情况不同，
找到适合自己的最重要 🌟

你们怎么看？欢迎交流～

#心得分享 #[相关话题]
```

## 语气与用词规范

| ✅ 推荐 | ❌ 避免 |
|--------|--------|
| 口语化、亲切感 | 书面语、过于正式 |
| 「姐妹们」「宝子们」「家人们」 | 「各位用户」「消费者」 |
| 「真的」「超」「绝」「巨」 | 「非常」「极其」「特别」 |
| 第一人称分享感 | 第三人称客观报道 |
| 具体数字和细节 | 模糊笼统的描述 |

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 风格规则与用户需求冲突 | 优先遵循用户明确要求，在备注中说明偏离原因 |
| 生成的内容过长 | 自动截断至 800 字以内，保持结构完整 |
| emoji 与主题不匹配 | 替换为更合适的 emoji，或删除 |
| 标签与内容无关 | 重新生成相关标签，确保精准度 |

## 使用说明

**触发方式**：content-creator agent 在生成推文时自动读取本 Skill。

**自定义扩展**：style-synthesizer 可通过分析用户提供的参考推文，更新本 Skill 中的风格规则和模板示例。
